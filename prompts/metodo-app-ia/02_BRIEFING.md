# 02 — Transformar a entrevista em briefing

Depois que a `01_ENTREVISTA.md` foi respondida, use este prompt para consolidar tudo num
Product Brief organizado.

```
Agora transforme todas as respostas da entrevista em um PRODUCT BRIEF completo.

Organize em:

1. Visão geral
2. Problema
3. Solução
4. Público-alvo
5. Persona principal
6. Jornada do usuário
7. Objetivo principal
8. Objetivos secundários
9. Funcionalidades
10. Regras de negócio
11. Conteúdo necessário
12. Estrutura de páginas
13. CTA principal
14. Integrações
15. Necessidades de banco de dados
16. Painel administrativo
17. Requisitos de segurança
18. Requisitos de responsividade
19. Identidade visual
20. Referências
21. O que evitar
22. Critérios de sucesso

Não escreva código ainda.

Se alguma informação estiver faltando, identifique claramente como:

[INFORMAÇÃO NECESSÁRIA]

Não invente informações.
```
