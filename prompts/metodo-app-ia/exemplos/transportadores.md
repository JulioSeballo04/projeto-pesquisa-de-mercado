# Exemplo — Controle de transportadores

Mostra como o método transforma uma página HTML simples num produto com cara de SaaS
industrial, estruturando o fluxo de navegação antes de implementar.

## Fluxo de navegação

```
LOGIN
 ↓
DASHBOARD
 ↓
LINHA
 ↓
TRANSPORTADOR
 ↓
COMPONENTES
 ↓
INSPEÇÕES
 ↓
ANOMALIAS
 ↓
OS
 ↓
HISTÓRICO
 ↓
INDICADORES
```

Cada etapa desse fluxo vira uma página/tela na fase de `04_ARQUITETURA.md`, com objetivo,
usuário, dados e ações próprias — em vez de uma página única listando tudo misturado.
