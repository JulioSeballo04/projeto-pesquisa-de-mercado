# 08 — Auditoria / QA

Último passo do método: uma auditoria completa antes de considerar o app pronto.

```
Faça uma auditoria completa da aplicação.

Teste mentalmente e, quando possível, valide:

AUTH
- cadastro
- login
- logout
- sessão
- recuperação de senha

CRUD
- criar
- visualizar
- editar
- excluir

UX
- loading
- erro
- sucesso
- vazio
- confirmação

RESPONSIVIDADE
- 320px
- 375px
- 390px
- 768px
- 1024px
- 1440px

NAVEGAÇÃO
- links
- botões
- voltar
- rotas protegidas

SEGURANÇA
- permissões
- dados privados
- Firestore Rules
- autenticação

PERFORMANCE
- imagens
- componentes
- carregamento

Aponte todos os problemas encontrados e corrija-os.
```
