# 01 — Entrevista do cliente

Primeiro prompt do método. Reutilizável em praticamente qualquer projeto: antes de construir,
a IA faz uma entrevista estratégica organizada em blocos, em vez de aceitar um pedido vago tipo
"crie um site para uma clínica".

```
Você será meu estrategista de produto digital.

Antes de escrever qualquer código, faça uma entrevista estratégica comigo para entender completamente o negócio, produto ou serviço que vamos transformar em um aplicativo/site.

NÃO construa nada ainda.

Faça perguntas organizadas por blocos.

BLOCO 1 — NEGÓCIO

1. Qual é o nome do negócio/projeto?
2. O que a empresa oferece?
3. Qual é o principal produto ou serviço?
4. Qual problema o negócio resolve?
5. Qual é o principal diferencial?
6. Quem são os principais concorrentes?
7. O que diferencia esse projeto dos concorrentes?

BLOCO 2 — PÚBLICO

8. Quem é o usuário ideal?
9. Qual faixa etária?
10. Qual nível de conhecimento tecnológico?
11. Qual poder de compra?
12. O usuário chega pelo celular ou computador?
13. Qual é o principal objetivo desse usuário?
14. Qual é a maior dor/frustração dele?
15. O que normalmente impede esse usuário de comprar, contratar ou utilizar o serviço?

BLOCO 3 — PRODUTO

16. Quais funcionalidades são obrigatórias?
17. Quais funcionalidades são desejáveis?
18. Existe login?
19. Existem diferentes tipos de usuários?
20. Existe painel administrativo?
21. Existem pagamentos?
22. Existe integração com WhatsApp?
23. Existe envio de e-mails?
24. Existe banco de dados?
25. Existe upload de arquivos/imagens?
26. Existe geração de relatórios?
27. Existe necessidade de notificações?

BLOCO 4 — CONVERSÃO

28. Qual é a ação principal que queremos que o usuário realize?
29. Comprar?
30. Agendar?
31. Entrar em contato?
32. Criar uma conta?
33. Solicitar orçamento?
34. Qual será o CTA principal?

BLOCO 5 — CONFIANÇA

35. Quais informações comprovam a autoridade da empresa?
36. Existem certificados?
37. Existem avaliações?
38. Existem depoimentos?
39. Existem números relevantes?
40. Existem cases?
41. Existem fotos reais?
42. Existem antes/depois?
43. Existem clientes conhecidos?

Não invente nenhuma informação factual.
Se algo estiver faltando, pergunte.

BLOCO 6 — IDENTIDADE

44. Existem cores oficiais?
45. Existe logotipo?
46. Existe manual de marca?
47. Existe alguma referência visual?
48. Quais sites/apps representam o estilo desejado?
49. O projeto deve parecer:
- premium
- tecnológico
- minimalista
- corporativo
- jovem
- sofisticado
- industrial
- futurista
- simples
- outro?

50. Quais estilos DEVEM ser evitados?

Depois que eu responder todas as perguntas, gere um briefing completo do produto.
```

## Por que funciona

As perguntas mais valiosas não são sobre tecnologia — são sobre UX e marketing: "qual
motivação representa melhor o cliente desejado?", "o que impede essa pessoa de agendar?", "o
que acontece depois do contato pelo WhatsApp?". É isso que separa um app genérico de um
produto desenhado para o negócio real.
