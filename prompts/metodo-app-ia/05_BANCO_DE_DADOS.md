# 05 — Banco de dados (Firebase Firestore)

Projeta o banco de dados antes de implementar — especialmente importante quando o projeto usa
Firebase/Firestore como padrão.

```
Agora projete o banco de dados da aplicação.

Utilizaremos Firebase Firestore.

Defina:

- collections
- documentos
- campos
- tipos
- relacionamentos
- índices necessários
- timestamps
- usuários
- permissões

Para cada collection explique:

collection:
campo:
tipo:
obrigatório:
descrição:

Depois gere:

1. estrutura Firestore
2. regras de segurança
3. índices necessários
4. estratégia de autenticação
5. estratégia de autorização

NUNCA permita que um usuário consiga acessar dados de outro usuário sem autorização.

Não implemente ainda.
Primeiro apresente a arquitetura.
```
