# 04 — Arquitetura do app

Aqui começa a diferença entre uma landing page e um aplicativo de verdade: páginas, rotas,
componentes, fluxos e estados, ainda sem implementar nada.

```
Agora transforme o briefing em uma arquitetura completa de aplicação.

Defina:

1. Páginas públicas
2. Páginas autenticadas
3. Dashboard
4. Perfil
5. Configurações
6. Área administrativa
7. Rotas
8. Componentes reutilizáveis
9. Estrutura de pastas
10. Modelos de dados
11. Relacionamentos
12. Permissões
13. Fluxos de usuário
14. Estados de loading
15. Estados vazios
16. Estados de erro
17. Validações
18. Responsividade
19. Integrações externas

Para cada página informe:

- objetivo
- usuário
- informações exibidas
- ações disponíveis
- componentes utilizados
- dados necessários
- regras de negócio

Não implemente ainda.
```
