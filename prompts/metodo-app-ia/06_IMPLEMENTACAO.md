# 06 — Implementação

Só agora, depois de briefing, design system, arquitetura e banco de dados definidos, a IA
constrói de fato.

```
Agora implemente a aplicação com base no briefing, design system e arquitetura definidos anteriormente.

REGRAS:

- Não altere decisões já definidas sem justificativa.
- Reutilize componentes.
- Evite código duplicado.
- Mantenha a arquitetura organizada.
- Utilize dados reais fornecidos no briefing.
- Não invente informações comerciais.
- Crie estados de loading.
- Crie estados vazios.
- Crie estados de erro.
- Faça validação dos formulários.
- Garanta responsividade.
- Garanta acessibilidade.

Antes de finalizar, revise:

- console errors
- erros de JavaScript
- rotas quebradas
- links quebrados
- problemas de responsividade
- problemas de overflow
- componentes inconsistentes
- problemas de contraste
- problemas de UX
```
