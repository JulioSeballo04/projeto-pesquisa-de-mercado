# 07 — Revisão de design ("designer crítico")

Depois que a IA construiu a aplicação, esse prompt pede uma segunda passada focada só em
acabamento visual — é o que evita a aparência de "template genérico de IA".

```
Agora aja como um diretor de arte e designer UX/UI sênior.

Analise a aplicação inteira procurando problemas de:

- hierarquia visual
- espaçamento
- alinhamento
- tipografia
- contraste
- consistência
- excesso de elementos
- excesso de cards
- aparência genérica
- aparência de template
- CTAs fracos
- imagens mal enquadradas
- responsividade
- experiência mobile

Não apenas diga o que está errado.

Faça as melhorias diretamente.

A aplicação deve parecer um produto criado por uma equipe profissional de design e desenvolvimento, e não uma interface genérica gerada por IA.

Priorize:

1. clareza
2. hierarquia
3. estética
4. usabilidade
5. conversão
6. consistência
```
